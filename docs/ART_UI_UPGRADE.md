# ART_UI_UPGRADE.md — 캐릭터·UI를 '프로처럼' 끌어올리는 방안

리서치 출처: Exa 232건 / 4개 서브에이전트(2026-06-23). 솔로 스팀 인디·CC0 진영의 실제 소싱 방식 + 코지/크리처 수집 게임 케이스 + 인디 UI 폴리시 + 빌드타임 AI 파이프라인.

## 0. 진단 — 지금 캐릭터가 '플레이스홀더'로 보이는 이유
현재 24종은 **손코딩 절차적 SVG**(도형 조합). docs/GAME_DESIGN.md §9가 처음부터 "도형 플레이스홀더 → AI 아트 교체(빌드타임)"로 명시했듯 **의도된 MVP 임시 에셋**이다. 리서치 결론: 절차적 접근 자체가 틀린 게 아니라(솔로 성공작 다수가 극단적 제약+모듈러로 성공), **'손그림 일러스트' 질감의 천장**이 낮을 뿐. 점프하려면 소스를 바꿔야 한다.

## 2. 추천 — **하이브리드: A(메인 업그레이드) + D(즉시 임시 폴리시)**
우리 제약(런타임 이미지 생성 금지·**빌드타임 AI 허용**·원작 IP 복제 금지·성인 더스티 파스텔)에 **A가 정확히 부합**한다. `scripts/gen-characters-openrouter.mjs` 스캐폴드도 이미 있음. 단기엔 D로 현 SVG를 덜 '도형'스럽게 다듬고, 본 업그레이드는 A로 24종 LoRA 로스터를 굽는다. 총비용 ~$30~120 + GPU.

## 3. 빌드타임 AI 워크플로 (코어 권장안)
1. **스타일 LoRA 학습** — 우리 아트 바이블(더스티 파스텔·점눈·2.5등신·어두운 외곽선·식별 소품1)을 담은 레퍼런스 20~30장(우리 SVG 렌더 + 무드보드)으로 학습. → **자체 레퍼런스로 학습 = 업스트림 학습데이터 IP 분쟁에서 격리**.
2. **캐릭터 시트 생성** — 종별 50자+ 앵커 설명 + 스타일 LoRA + 레퍼런스 이미지로 컨셉 50~100장 → 24 디자인 확정.
3. **일관성 잠금** — 캐릭터 LoRA(시트 15~30장, 800~1200스텝) + IP-Adapter 멀티레퍼런스(가중치 0.55, 안전망). 패밀리 응집은 스타일 LoRA가 담당.
4. **클린업** — BiRefNet/Bria 배경제거(머리카락 매팅) → 마젠타 크로마키 잔여 0 → 512² 정규화. (docs/RISKS.md: flood-fill 금지, 크로마키만)
5. **사람 검수 게이트** — 24종 나란히 패밀리 매트릭스, IP 유사성·손/눈 아티팩트 점검, 5~10%만 인페인트 수정. **사람 큐레이션을 문서화**(docs/ASSETS.md에 prompt·seed·모델·선별/수정 내역).
6. **커밋** — 사람 검수 통과분만 `assets/characters/`로 교체 후 `--import`. (런타임 호출 0 — 규칙 준수)

**도구:** ComfyUI+Flux 2(로컬·무료, JSON 워크플로 git 커밋), 픽셀이면 Retro Diffusion/SpriteBrew, 정리 Aseprite($20). 대안 SaaS: Scenario.gg/Layer.ai($15~100/월, IP 인뎀니티 옵션).

## 4. 법적·스팀 (출시 전 필수)
- **순수 AI 생성물은 미국 저작권 보호 없음**(USCO 2025·Thaler 항소심). → 경쟁사가 복제 가능. **방어책: 사람의 창작적 기여(스케치·큐레이션·인페인트·배치)를 문서화**하고 그 부분으로 권리 주장. 자체 레퍼런스 LoRA로 학습데이터 오염 회피.
- **Steam AI 공시**(2026-01 개정): 출하되는 사전생성 AI 아트는 Steamworks 콘텐츠 설문에서 **공시 의무**(스토어 노출). 개발 보조(코딩 등)는 면제. → 출시 시 정직 공시.
- 모바일(iOS/Play)은 명시적 AI 공시 의무 없음(2026 기준) — 우리 1차 타깃과 부합.

## 5. UI 개선
현재 이미 양호(Lucide ISC 아이콘·9슬라이스 카드·코지 라이트·주스). 갭만 메운다:
- **코지 라운드 폰트**로 교체/병행 — 라틴 [Comfortaa](https://fonts.google.com/specimen/Comfortaa)·[Open Runde](https://github.com/lauridskern/open-runde)(OFL), **한글 라운드** [Sunghyun Sans](https://sans.cho.sh)(OFL). 현 Pretendard는 깔끔하나 '코지' 정서는 약함.
- 폴리시 체크리스트 잔여: 8px 그리드 일관·≥48px 터치타깃·텍스트 대비 4.5:1·폰트 ≤3종·정보 위계(중요만 노출).

## 7. 우선순위 / 비용 요약
1. **(즉시·$0) D 폴리시** — SVG 셰이딩·라인·소품 디테일 1패스 + 코지 폰트 교체.
