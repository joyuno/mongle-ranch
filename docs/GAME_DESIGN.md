# 최종 컨셉 결정서 — 게임 디렉터 승인안

## 1. 게임 이름 · 한 줄 컨셉

**「몽글목장」 (가칭, 영문 코드명: mongle-ranch)**
"퀴즈를 풀면 몽글몽글한 친구들이 목장에 찾아온다 — 공부가 곧 먹이이고, 친구들은 절대 떠나지 않는다."

장르 포지셔닝: 퀴즈 학습 × 비전투 수집 가챠 × 관찰형 목장 (2026년 '데스크톱 펫+코지 수집' 트렌드 직격).

## 2. 코어 루프

```
[퀴즈 사다리 세션] ── 상금 코인 ──→ [가챠 1,000코인] ──→ [캐릭터 획득]
      │                                                      │
      ├─ 정답 1개 = 보유 캐릭터 중 랜덤 1마리 레벨 +1            ↓
      ├─ 누적 정답 30개 = 무료 가챠 티켓 1장              [목장에서 배회·관찰]
      │                                                      │
      └─ 중복 캐릭터 → 합성(레벨 합산)                          ↓
                                            [NPC 시장 판매] ── 코인 ──→ 가챠/꾸미기
```

- **퀴즈 사다리 (GitAnimals quiz 모듈 차용, 10배 스케일다운)**: 세션당 5문제(쉬움2/보통1/어려움2), 문제당 10초. 상금 200 → 400 → 800 → 1,600 → 3,200코인(정답마다 2배). 정답 직후 "그만두고 확정" 선택 가능, 오답/시간초과 시 **그 세션 상금만** 0.
- **무처벌 원칙(Finch)**: 사다리 실패해도 캐릭터 레벨업·30정답 티켓 누적은 항상 지급. 미접속 시 캐릭터가 굶거나 떠나는 메커니즘 영구 금지. 일일 스트릭 복구는 **무료 복구권 우선**(스트릭 7일마다 +1, 최대 2개) → 없을 때만 코인 2,000(Duolingo 2026: 프리즈 보유 시 리텐션 +48%, docs/RESEARCH_PASS2.md §E). 유료 온디맨드 + 무료 간헐의 비대칭으로 처벌이 아닌 보살핌을 신호.
- **레벨의 의미**: 능력치 없음. 판매가 보정 + 합성 재료 + (후속) 진화 조건. "누가 클지 모르는" 랜덤 레벨업이 애착 장치.
- **합성(Merge)**: 중복 캐릭터를 제물로 영구 삭제하고 레벨을 대상에 합산 — 가챠 중복 해소의 유일 경로(별조각 시스템은 도입하지 않음, Minimize code).
- **진화(레벨 100)**: MVP 제외, 로드맵 항목. MVP에서는 레벨 50/100 도달 시 런타임 오버레이(반짝 파티클+칭호)로 대체 — 에셋 추가 생성 없이 구현.
- **가챠**: 1회 1,000코인(1~10연). 천장 3단 — 10연 내 에픽 이상 보장 / 30연부터 레전더리 확률 +10%p씩 점증, 40연 하드 천장 / 100연 누적 스파크(원하는 캐릭터 선택권). 일일 코인 적립 상한 20,000.

## 3. GitHub 연동의 역할 — "간식 배달부" (보조 재화, 단방향, 무토큰)

- **username만 입력. 토큰 입력 UI는 만들지 않는다** (보안팀 high 권고 그대로).
- 무인증 `GET /users/{u}/events`에서 `PushEvent.payload.distinct_size` 합산, **증분 적립 모델** (누적 총 커밋 추적 안 함).
- 환산: **커밋 1개 = 간식 1개, 일일 캡 10개**. 간식 용도: 목장에서 캐릭터에게 주면 레벨+1 + 기뻐하는 이모트. **간식으로 가챠 불가** → 학습 우위 수치로 강제.
- 구현: `GithubSync` 오토로드 1개(HTTPRequest 1노드, await 패턴), `user://github_cache.json` TTL 30분, User-Agent 헤더 명시, 403/429 시 X-RateLimit-Reset까지 백오프, **모든 실패는 비차단**(캐시 폴백, 게임은 퀴즈만으로 완결). 연동 자체가 선택 기능.

## 5. 시장 시스템 (NPC 회전 시장 — 동물의숲 시세 모델)

- **기본가(판매 기준)**: common 300 / rare 1,200 / epic 5,000 / legendary 20,000 코인.
- **판매가** = 기본가 × m × (1 + 0.02 × 레벨), m = 일일 시세 계수.
- **구매가(NPC 매물)** = 판매가 × 2.3 (스프레드 ~57%가 주 인플레 싱크).
- **시세 m**: 랜덤워크, 전일 ±0.10, [0.85, 1.15] 클램프. 주 1회 '인기일'에 특정 희귀도만 1.3~1.6× — "언제 팔까" 메타게임.
- **NPC 매물**: 매일 무작위 3~5마리 회전(weight 기반 가격). **일일 판매 상한 3마리**(가챠→시장 차익 덤핑 차단).
- 보조 싱크: 한정 배경/장식 판매(2,000~5,000), 이름 변경 500, 스트릭 복구 2,000.
- 검증 게이트: 구현 전 "하루 30문제 × 30일" 시뮬 스크립트로 코인 곡선 확인(목표: 30일차 레전더리 1~2, 잔고가 10연 비용 2배 미만).

## 6. 캐릭터 랜덤 활동 (목장 화면)

- **구현**: Control 마당 + 캐릭터(Control 루트 + TextureRect 자식) 소형 씬. SubViewport/Node2D 불사용 — 기존 코드베이스의 Tween 패턴 그대로.
- **상태머신**: idle ↔ walk ↔ sleep ↔ special. `await create_timer(randf_range(1,4))` 대기 → 마당 내 랜덤 목표점 → `tween_property(position)` 이동(거리/속도로 duration), 방향은 flip_h.
- **생명감 레시피(단일 PNG)**: pivot_offset 발밑 고정 + 숨쉬기 squash&stretch(1.04/0.96, 개체별 랜덤 주기로 동기화 방지) + 걷기 중 y 바운스 + 발밑 그림자 타원 + 가챠 등장 TRANS_ELASTIC.
- **이모트 말풍선**: 5~30초 무작위 간격으로 머리 위 감정 표시(GitAnimals buildEmotionAnimation 번안). 성격별 풀 차등(4번 표 참조).
- **상호작용**: gui_input 클릭 → 기쁨 점프 + 울음소리, 간식 주기, 드래그로 집어 옮기기. position.y 기준 move_child 유사 Y-sort.
- 표시 상한 30마리 + 초과분 인벤토리(도감에서 교체).

## 8. 반드시 피해야 할 것 (리스크 high 전부 반영)

1. **프롬프트·코드·문서·커밋·마케팅 어디에도 특정 카와이 IP의 캐릭터명·작가명, 타 IP 캐릭터명을 쓰지 않는다.** 생성 스크립트에 금지어 검증 로직 하드코딩. 일반 기술어(kawaii minimal mascot, chibi, dot eyes)만 사용.
2. **기존 IP 캐릭터와 식별 가능한 외형·이름·설정 금지** — 특정 인기 IP 트리오의 시그니처 외형 조합 회피. 출시 전 육안 대조 게이트.
3. **GitAnimals 에셋·펫 이름·UI 구성 복제 금지** (라이선스가 디자인 사용을 명시적으로 금지). 메커니즘·수치만 독자 구현. README에 "inspired by" 한 줄만 허용.
4. **GitHub 토큰 입력 UI를 만들지 않는다.** username-only 무인증 + 캐시.
5. **런타임 이미지 생성 API 호출 금지.** 빌드타임 스크립트 생성 → 사람 검수 → res:// 커밋. 게임 바이너리에 생성 엔드포인트 코드 자체를 넣지 않음.
6. **'Pollinations flux 무료' 전제 폐기** (실측 402/401). 1순위: 도형 플레이스홀더로 게임플레이 선행 개발 → 2순위: OpenRouter Gemini(~$0.7/12종, 네이티브 알파, 기존 검증 경로) → Pollinations는 무료 키 발급 확인 시에만.
7. **흰배경 flood-fill 배경 제거 금지** (파스텔에서 깨짐 입증). 마젠타 크로마키 또는 네이티브 알파 모델. v2의 strip-bg.mjs는 교체.
8. **멀티포즈 시리즈 생성 시도 금지.** 1캐릭터=1이미지 + Godot 트윈으로 표현.
9. **무처벌 원칙 위반 금지** — 펫 굶김·이탈·퇴화 메커니즘 일체 불가.
10. **repo 초기화 전 .gitignore(.env 포함) 먼저** + export preset에 비리소스 미포함. **코드 MIT / 에셋 ASSETS-LICENSE 분리**, ASSETS.md에 모델·시드·프롬프트·생성일·리터치 내역 기록, AI 생성 고지.
11. 퀴즈 렌더링 bbcode_enabled=false 유지, 파서에 문항 2KB·1,000문항 상한 추가. 팩 포맷은 JSON 고정(.tres/ZIP 확장 금지).

## 9. 채택하는 차별화 아이디어 (3개)

1. **더블 오어 나씽 퀴즈 사다리** — "한 문제 더? 여기서 확정?" 의사결정이 단순 문답을 긴장감 있는 학습 세션으로 바꿈. 본가 GitAnimals quiz 모듈로 검증된 구조.
2. **공부 동행 모드** — Forest의 '집중 시간 = 재화' 공식 차용. 25분 타이머 동안 수집한 캐릭터들이 화면에서 같이 공부하는 연출 + 완료 시 간식. 퀴즈(단발)와 집중(누적)의 이중 루프이자 "노력하는 작은 친구들" 감성의 핵심 연출.
3. **데스크톱 펫 모드 (post-MVP 로드맵)** — Godot 투명·항상-위 창으로 수집 캐릭터가 실제 바탕화면을 배회. 2026년 Steam 신규 트렌드 직격이며 GitAnimals(README 안)·Finch(앱 안)가 못 하는 경험. MVP 범위에서는 제외하되 캐릭터 씬을 마당 의존 없이 설계해 이식 경로 확보.

**구현 우선순위(MVP)**: 도형 플레이스홀더 12종 → 목장 배회 + 퀴즈 사다리 + 가챠 + 도감/합성 → 시장 → GitHub 간식 → AI 아트 교체(빌드타임) → 공부 동행 모드.
